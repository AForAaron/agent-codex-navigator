# 连续五小时保护

同一次渲染器运行内，开启保护后持续循环：原生套餐耗尽或点数余额补充触发→暂停可控任务→等待新原生额度确认→接续本功能暂停的任务→清理本周期触发记录并继续监听下一窗口。模式和本机控制锁不因周期完成而关闭。

窗口由服务端原生到期时间识别，不机械地每五小时启动。显示倒计时不是恢复依据；五小时恢复但每周额度仍耗尽时不恢复。模型受限则保留任务记录继续等待。关闭、账号切换、手动停止、新轮次或目标/模型变化都按原取消规则处理。失败交付不自动重试。

完成周期后清理停止时间、旧窗口与本周期点数基线，保留保护开启状态；诊断completedCycles仅在内存中统计完成循环，不保存正文或余额。回归用五个连续模拟窗口确认每周期只中断/接续一次及旧证据不能恢复。

覆盖仅为可验证的本机已加载Codex普通轮次和Goal。其他设备、CLI、云端、子代理和未加载任务尚不构成全账号保护。完整退出、刷新或重新加载插件后暂停记录不会持久恢复，须重新开启；这是当前实现边界。尚未完成真实账号连续两个自然五小时窗口的耗尽/恢复计费验收，模拟测试不代替该证据。
